# Python Async Comprehension

This directory contains exercises about asynchronous generators
and asynchronous comprehensions.

## 0. Async Generator

The `0-async_generator.py` module defines an asynchronous generator.

The `async_generator` function:
- Takes no arguments.
- Loops exactly 10 times.
- Waits one second during each iteration.
- Yields a random floating-point number between 0 and 10.
- Uses an AsyncGenerator return type annotation.
